# 🔴🪟 Red Team na Windows

> **Kompendium wiedzy ofensywnej i detekcyjnej** — stan na sierpień 2026

## 📖 Czytaj online: [zi3lak.github.io/redteam-na-windows](https://zi3lak.github.io/redteam-na-windows/)

Kompletna ścieżka operacji red team w środowiskach **Windows i Active Directory** — od initial access po dominację domeny. Wszystko zmapowane na **MITRE ATT&CK** 🎯 i opatrzone kontrapunktem detekcyjnym 🛡️

### Co znajdziesz w środku? 🔥

- 🥔 **Rodzina ataków Potato** — warianty działające na w pełni załatanych systemach
- 🎫 **Kerberoasting, AS-REP roasting, DCSync** — gra o tożsamość w AD
- 📜 **AD CS (ESC1–ESC8)** — eksploatacja certyfikatów domenowych
- 🛡️ **Unikanie EDR** — direct syscalls, BYOVD, NTLM relay (CVE-2025-33073)
- 🔍 **Telemetria detekcyjna** — Sysmon, Security Log, ETW, konkretne Event ID
- ⚡ **Dlaczego 82% ataków jest malware-free** — i co to znaczy dla obrońców

### ⚠️ Zastrzeżenie

Materiał **wyłącznie** do celów edukacyjnych, autoryzowanych testów bezpieczeństwa i budowania detekcji. Użycie opisanych technik bez pisemnej zgody właściciela systemu jest przestępstwem (art. 267–269 KK).
